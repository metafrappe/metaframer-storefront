# Self-hosted fonts

DM Sans and Manrope are distributed under the SIL Open Font License 1.1.
The corresponding license and copyright notices are included in this directory.

The WOFF2 Latin and Latin Extended subsets were downloaded from the official
Google Fonts CSS service on 2026-09-17; the extended subsets include Turkish glyphs.
Fonts are served locally; the application does not request Google Fonts at runtime.

Sources:
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/manrope
